# portfolio-site

Сайт-портфолио: услуги, кейсы, стек, процесс и честный блок «Кто я и откуда».

**Живая версия:** https://alexvoron-portfolio.spru.site/

## Что внутри

- `index.html` — разметка и контент
- `styles.css` — стили, адаптив от 360 px
- `app.js` — интерактив: мобильное меню, плавная навигация, копирование ссылки на демо

Контент редактируется прямо в разметке: услуги — блок `#services`, кейсы — `#cases`, контакты — блок `#about`.

## Как опубликовать

Это статический сайт без сборки: подойдёт любой хостинг (GitHub Pages, Vercel, Netlify, Cloudflare Pages). Достаточно загрузить три файла из корня репозитория.

## Честно о содержании

Цифры в кейсах и тексты отзывов — модельные, они помечены как демонстрационные. Рабочие части — код бота, сценарий n8n и их документация — лежат в отдельных репозиториях: `voron-lead-bot`, `n8n-lead-to-crm`.
